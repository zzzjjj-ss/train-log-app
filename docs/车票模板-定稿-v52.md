## 二、文字排版（v52，最终定稿）

**字体**：非衬线黑体 = Noto Sans CJK；衬线宋体 = Noto Serif CJK。
**规则**：全部不加粗；数字黑体（R093443 那种非衬线）、汉字宋体；数字旁汉字小一号。
**基线**：anchor='la'（左上）顶部对齐。

### L1 顶部行（y94）
- `R093443`：x12，黑体 6.5，**半透明红 `(205,45,45,α215)`**
- `检票口22`：x159 右对齐，宋体 6，黑

### L2 站名+车次（y99）
- 站名主体（`北京南`/`天津`）：黑体 9.5，起点动态计算使**站名到票边距 = 站名到车次距**：
  - `x_bj = (xc0 + 9 - ws_bj)/2`（xc0 = 车次左端）
  - `x_tj = (162 + xc1 - ws_tj)/2`
- `站`：宋体 5.5，紧随主体（`x + w(主体) + 0.5`，`y + (9.5-5.5)` 底部对齐）
- 车次 `C2565`：**宋体** 9.5，居中 x86

### L3 拼音（y113.5）

## 三、关键决策记录（防回退）

| 项 | 结论 |
|----|------|
| 字体 | 数字黑体非衬线、汉字宋体、全部不加粗、数字旁汉字小一号 |
| R093443 | 黑体、半透明红 α215、不加粗 |
| 站名 | 主体黑体9.5 + "站"宋体5.5，到车次距=到票边距 |
| 左边距 | 日期/价格/网/限乘/身份证统一 x20 |
| 虚线框 | 上下 padding 相等(0.2)，下边框不越色带 |
| 二维码 | 正方形、无边框、22×22 |
| 色带 | 编号+空格+发售地，黑字，左对齐 |
